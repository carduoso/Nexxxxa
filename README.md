# Nexxa: landing page
Arquivos: index.html (conteúdo), styles.css (visual), main.js (interações + CONFIG de contato).
Executar: abra index.html, ou rode `npx serve .` / extensão Live Server do VS Code.
Configurar: em main.js preencha CONFIG.formEndpoint (Formspree/Web3Forms) e/ou CONFIG.whatsappNumber (só dígitos, com DDI).
Publicar: arraste a pasta no Netlify Drop, ou use Vercel, Cloudflare Pages ou GitHub Pages. Site estático, sem build.
